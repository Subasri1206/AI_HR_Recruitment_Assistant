TalentPulse AI: HR Recruitment Assistant

Academic Project Final Report & System Documentation
Domain: Artificial Intelligence & Web NLP
Architecture: Agent + RAG Vector Retrieval
Deployment: Single-Page App (SPA) / PowerShell Server

1. Executive Summary

TalentPulse AI is an advanced, production-grade Artificial Intelligence HR Recruitment Assistant designed to automate and enhance talent acquisition workflows. Modern HR teams face significant challenges screening hundreds of resumes per job opening, leading to evaluation delays, subjective bias, and unstandardized candidate matching. TalentPulse AI addresses these challenges by offering an interactive recruitment workspace equipped with multi-stage resume parsing, an explainable 0-100% match scoring engine, automated personalized interview question generation, side-by-side candidate comparisons, and an AI conversational agent.

2. Problem Statement & Project Objectives

Traditional recruitment systems suffer from three primary bottlenecks:

  1. Manual Resume Screening Overhead: Recruiters spend an average of 6-10 seconds per resume, increasing the likelihood of missing highly qualified candidates.
  2. Black-Box Automation: Traditional keyword search tools fail to explain why a candidate matches or what specific qualification gaps exist.
  3. Unprepared Technical Interviews: Interviewers often ask generic questions that fail to cross-examine specific claims made on a candidate's resume.

Project Objectives:

  • Develop a web-based workspace enabling recruiters to create jobs and ingest resumes via native file upload.
  • Implement a multi-factor transparent matching engine providing detailed 0-100% score breakdowns.
  • Automate candidate interview preparation with customized questions and a 30-minute interview agenda.
  • Integrate client-side localStorage data persistence ensuring zero data loss upon page refresh.
  • Design a modern, accessible user interface with a collapsible sidebar and responsive layout.

3. System Architecture & Core Modules

Module 1: Resume Ingestion & Parsing

Processes PDF, DOC, DOCX, and TXT files using native file browser APIs (`FileReader`). Extracts candidate contact info, total experience, skills, summary, and work history.

Module 2: Explainable Match Engine

Calculates multi-factor candidate scores against job descriptions using configurable weights. Generates transparent score breakdowns and extracts exact resume evidence snippets.

Module 3: Interview Question Generator

Synthesizes personalized technical, behavioral, and resume-claim questions. Provides evaluation rationales, expected answer signals, and a 30-minute interview breakdown.

Module 4: AI Agent Workspace & Tools Router

Conversational assistant capable of handling natural language queries ("Rank candidates for Senior React Engineer") with visible tool execution traces.

Module 5: Side-by-Side Candidate Comparison

Enables recruiters to select any two candidates and render a side-by-side comparison of skills, experience, and match metrics.

Module 6: Data Persistence & CRUD Operations

Includes full Edit and Remove capabilities for Candidates and Jobs, automatically synchronized with browser `localStorage`.

4. Match Scoring Mathematical Model

The candidate matching engine evaluates alignment using a weighted linear combination model:

Overall Match Score (S) = ∑ (Weight_i × Score_i)
S = (35% × Required_Skills) + (20% × Exp_Years) + (15% × Responsibilities_Fit) + (10% × Domain_Fit) + (10% × Preferred_Skills) + (10% × Education & Certs)
Scoring Factor Default Weight Evaluation Criteria
Required Skills Fit 35% Exact and fuzzy keyword matching of mandatory job technical skills.
Experience Duration 20% Candidate total experience years compared against job minimum threshold.
Responsibilities Alignment 15% Textual and semantic overlap between candidate resume achievements and job responsibilities.
Domain Alignment 10% Industry domain keywords (e.g., Enterprise SaaS, AI, Cloud Infrastructure).
Preferred Skills Fit 10% Evaluation of secondary, nice-to-have technical competencies.
Education & Certifications 10% Verification of academic degrees and technical certifications (e.g., AWS, PMP).

5. Technical Implementation & Stack

  • Frontend Framework: Single-Page Application (SPA) built with React 18, React DOM, and Babel Standalone in-browser compilation.
  • Styling & Motion UI: Tailwind CSS for glassmorphism styling, CSS Keyframes (`fadeIn`, `slideRight`, `pulseGlow`), and custom transition curves.
  • Iconography & Typography: Lucide Icon library and Google Fonts (Plus Jakarta Sans & JetBrains Mono).
  • Backend Web Server: Standalone PowerShell script (`server.ps1`) utilizing `System.Net.HttpListener` on port `5174` (with automatic port fallback 5173-5185). Configured with CORS and `Cache-Control: no-cache` headers.
  • Storage & State Engine: Browser `localStorage` for zero-backend data persistence across page reloads.
  • Error Resilience: React `` component catching unexpected runtime errors and presenting a friendly recovery UI.

6. Ethical & Responsible AI Framework

TalentPulse AI adheres to strict Responsible AI guidelines. Candidate evaluations are performed strictly against job-relevant skills, documented experience, and verified resume evidence. Demographic attributes such as age, gender, race, location, or educational institution prestige are explicitly excluded from score calculations to ensure unbiased talent acquisition.

7. Conclusion & Future Enhancements

The **TalentPulse AI** platform successfully demonstrates a complete, production-grade recruitment assistant application. By combining automated resume parsing, explainable match scoring, personalized question generation, interactive chat, and persistent local storage, it significantly streamlines candidate evaluation for hiring managers.

Future Enhancements: Integrations with live PostgreSQL `pgvector` databases for enterprise semantic search, automated video interview sentiment parsing, and direct integration with Applicant Tracking Systems (ATS) like Greenhouse and Lever.
